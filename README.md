# 🌾 Smart Farming Analysis Dashboard – Excel

## 📌 Project Overview

The **Smart Farming Analysis** project is an Excel-based data analytics and dashboard project designed to analyze agricultural data and generate meaningful insights into **crop performance, yield, revenue, profit, soil type, and regional performance**.

The project uses Excel data analysis techniques, Pivot Tables, formulas, charts, and an interactive dashboard to transform raw farming data into actionable business insights.

## 🎯 Project Objective

* Analyze crop-wise and region-wise farming performance
* Identify high-performing crops and regions
* Analyze revenue, profit, and yield trends
* Compare crop performance across different soil types
* Identify patterns and trends in agricultural data
* Build an interactive Excel dashboard for decision-making

## 🔍 Analysis Performed

### 1. Crop Analysis

Analyzed crop-wise yield, revenue, profit, and overall performance to identify the most and least performing crops.

### 2. Regional Analysis

Compared farming performance across different regions to identify high-performing and low-performing areas.

### 3. Soil Type Analysis

Analyzed the relationship between soil types and crop yield to understand which soil conditions support better agricultural performance.

### 4. Year-wise Analysis

Analyzed revenue, profit, and yield trends across different years to identify changes in farming performance.

### 5. Profitability Analysis

Compared revenue and costs to evaluate profit performance and identify areas with better profitability.

## 💡 Key Insights

* Identified high-performing crops based on yield and profitability.
* Compared regional performance using revenue, profit, and yield metrics.
* Analyzed the impact of soil type on crop yield.
* Identified year-wise changes in revenue and profit.
* Created KPI-driven reporting to support data-based agricultural decisions.
